# The Daily Brew — Official Café Website

A premium, editorial café web experience built with **React**, **Vite**, **Tailwind CSS**, and **Lucide Icons**, inspired by the visual craftsmanship and aesthetic standard of **ARAKU Coffee** (`arakucoffee.in`).

---

## ☕ Project Overview

- **Project Name:** The Daily Brew
- **Location:** Chennai, India
- **Live Local URL:** [http://127.0.0.1:5173/](http://127.0.0.1:5173/)
- **Technology Stack:** React 19, Vite, Tailwind CSS v4, Lucide React

---

## 🎨 Design System & Palette

- **Forest Green (`#183D32`):** Primary brand accent conveying depth, organic coffee heritage, and sophisticated warmth.
- **Warm Cream (`#F5EBDD` / `#FAF5ED`):** Background tone reminiscent of artisan parchment and steamed milk froth.
- **Terracotta (`#C66A42`):** Vibrant call-to-action color evoking roasted beans, clay espresso cups, and warm Chennai afternoons.
- **Espresso (`#30251F` / `#0E251E`):** Deep roasted coffee color for primary typography, borders, and footer.
- **Typography:** *Playfair Display* (Editorial Serif) paired with *Plus Jakarta Sans* (Modern Clean Sans-Serif).
